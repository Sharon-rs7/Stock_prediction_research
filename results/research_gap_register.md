# Empirical Research Gap Register

This document tracks all identified methodological, empirical, and statistical gaps throughout the lifecycle of the project:
**"Machine Learning Framework for Stock Price Forecasting and Similar-Stock Recommendation Using Historical OHLCV Data"**

---

| Gap ID | Gap Description | Methodological Rationale & Impact | Severity | Proposed Solution | Required Experiment / Action | Status | Empirical Evidence / Validation Artifact |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **GAP-001** | Absence of a Random Top-5 Recommendation Baseline | Finite-sample selection ($k=5$) naturally inflates return variance compared to the 2,434-stock universe benchmark. Without a random 5-stock baseline, reviewers can argue excess variance is an artifact of sample size rather than model selection. | **High** | Construct a Monte Carlo Random Top-5 baseline ($B=100$ iterations per rebalance date) across identical target stocks and eligible cross-sections. | Run Monte Carlo Random Top-5 simulation on out-of-time test dates. | **Resolved** | Verified across 122,000 random portfolios: Mean Excess $= +0.01\%$, Std $= 3.43\%$, HitRate $= 47.27\%$. Proves Method A's $12.03\%$ std is driven by high-dispersion asset selection, not small sample size (`results/experiments/random_baseline_summary.json`). |
| **GAP-002** | Justification of Fusion Weight $\alpha = 0.5$ Without Test Snooping | A reviewer could argue that $\alpha=0.5$ was cherry-picked or snooped on the test partition. | **High** | Perform a systematic alpha grid search $\alpha \in [0.0, 0.1, \dots, 1.0]$ strictly on the Validation partition ($2024-04-08 \rightarrow 2025-06-27$) to establish the validation frontier before test evaluation. | Validation partition parameter sweep across fusion weights. | **Resolved** | Completed across 11 alpha levels on 62 validation rebalance dates: confirmed monotonic variance reduction from $13.42\%$ ($\alpha=0$) down to $3.10\%$ ($\alpha=1.0$), with $\alpha=0.5$ achieving $3.95\%$ std and positive excess return $+0.29\%$ (`results/experiments/validation_alpha_frontier.json`). |
| **GAP-003** | Portfolio Turnover and Transaction Cost Friction Analysis | High arithmetic returns in weekly rebalancing ($H=5$) may be eroded by transaction costs and high turnover. Furthermore, the hypothesis that Method C acts as a turnover damper must be empirically tested. | **High** | Compute two-way portfolio turnover between consecutive rebalance periods for Methods A, B, and C. Simulate net excess returns under 10 bps, 20 bps, and 30 bps round-trip transaction costs. | Turnover tracking and transaction-cost sensitivity analysis. | **Resolved** | Empirically quantified: Method B has $9.0\%$ turnover, Method A has $72.7\%$, Method C has $83.8\%$. At 10 bps, Method C remains positive ($+0.08\%$); at 20 bps it reaches neutral ($-0.01\%$) (`results/experiments/turnover_and_costs_summary.json`). |
| **GAP-004** | Formal Synthetic Validation of the Similarity Engine | Reviewers require formal verification that the similarity engine exhibits expected mathematical properties on known controlled signals without look-ahead. | **Medium** | Create synthetic tests with known identical (+1.0), inverse (-1.0), and orthogonal (0.0) time-series to verify mathematical convergence and self-exclusion. | Synthetic controlled unit test script. | **Resolved** | 100% passed in `scripts/verify_similarity_synthetic.py`: identical correlation $= +1.0000$, inverse $= -1.0000$, orthogonal $= +0.0222$, self-match excluded. |
| **GAP-005** | Non-Parametric & Bootstrap Statistical Inference | Return distributions are heavy-tailed and non-normal. Relying exclusively on Student's $t$-tests may misstate significance. | **Medium** | Compute paired two-tailed Wilcoxon signed-rank tests and stationary bootstrap standard errors across recommendation rebalance dates. | Non-parametric statistical inference module. | **Resolved** | Completed: Method A Wilcoxon $p = 0.0159$ (95% CI $[+1.00\%, +2.34\%]$), Method B $p = 0.2266$ (95% CI $[-0.25\%, +0.19\%]$), Method C $p = 0.9181$ (95% CI $[-0.08\%, +0.39\%]$) (`results/experiments/nonparametric_inference_summary.json`). |
| **GAP-006** | Complete Feature-by-Feature Timestamp Leakage Audit Table | Section 11 of the validation protocol requires a dedicated CSV documenting the latest information timestamp, future data usage, and verification status for all 30 features. | **High** | Programmatically verify and output `results/feature_leakage_audit.csv`. | Feature audit script verifying analytical formulas and causal lag invariants. | **Resolved** | Generated `results/feature_leakage_audit.csv`: all 30 features confirmed PASS with $0.00\text{e}+00$ max perturbation delta. |
| **GAP-007** | Comprehensive Dataset Sanity and Distributional Validation Report | Section 10 requires an exhaustive data sanity report auditing missing values, infs, price positivity, volume distributions, and panel synchronization. | **Medium** | Scan the full 4,283,165 row panel and generate `results/data_validation_report.md`. | Automated full-panel sanity check script. | **Resolved** | Generated `results/data_validation_report.md`: 0 non-positive prices, 0 infs, 0 duplicate keys, exact 1,759 dates for all 2,435 tickers verified. |
