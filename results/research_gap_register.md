| **GAP-001** | **RECOMMENDATION** | Absence of a Random Top-5 Recommendation Baseline | **High** | Holding a small $k=5$ portfolio naturally inflates return variance compared to the 2,434-stock universe benchmark. Without controlling for finite-sample size $k$, reviewers can claim Method A's high volatility is merely an artifact of small portfolio size rather than model selection. | Implement a Monte Carlo Random Top-5 baseline ($B=100$ draws per rebalance date across identical target stocks and eligible cross-sections). | Simulate 122,000 independent random portfolios across test dates. | **RESOLVED** | Random Top-5 standard deviation is $3.43\%$ vs Method A's $12.03\%$, proving Method A actively selects extreme high-dispersion/tail-risk equities (`results/experiments/random_baseline_summary.json`). |
| **GAP-002** | **RECOMMENDATION** | Justification of Fusion Parameter $\alpha = 0.5$ Without Test Snooping | **High** | Setting $\alpha=0.5$ could be challenged as arbitrary or cherry-picked post-hoc on the test partition, constituting data snooping. | Perform a systematic alpha grid search $\alpha \in [0.0, 0.1, \dots, 1.0]$ strictly on the out-of-time Validation partition ($2024\text{--}2025$), keeping the Test partition untouched. | Validation partition parameter sweep across fusion weights. | **RESOLVED** | Monotonic variance reduction confirmed from $13.42\%$ ($\alpha=0$) down to $3.10\%$ ($\alpha=1.0$), with $\alpha=0.5$ achieving $3.95\%$ std and $+0.29\%$ excess return (`results/experiments/validation_alpha_frontier.json`). |
